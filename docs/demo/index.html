Moedinha

Demonstração clicável do app de cara ou coroa para Android. O diferencial é o widget: gire a moeda direto da tela inicial.

Toque no ícone da Moedinha na tela inicial para abrir o app no outro celular. Toque na moeda do widget para girar sem abrir o app. É uma simulação em página web; o app de verdade é nativo para Android. Código no GitHub.
